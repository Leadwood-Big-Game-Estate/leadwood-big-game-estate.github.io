Change the password

This page changes nothing by itself: it computes the hash to copy into config.js.

The line to copy will appear here.
  1. Open config.js in the GitHub repository, then the pencil icon.
  2. Replace the line window.LW_GATE_HASH = "…"; with the one above.
  3. Confirm with Commit changes. The new password applies within a minute.

Every device already unlocked will ask for the password again after this change — that is expected, and it is the point: a lost phone loses access as soon as you change the line.

This check runs in the browser and can be bypassed by anyone who reads the page's code. It keeps the curious out, not an attacker. The real protection of the sightings is the Supabase accounts.
